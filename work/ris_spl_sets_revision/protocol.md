# Conditional coverage and rank perturbations

Project-local design frozen before the first run of these revision experiments on 19 November 2026. All protocols retain the original pairwise confidence-set receiver, family error budget 0.05, 14 feasible pairs, all-24 fallback after conflict, four two-cell surfaces, two transmit and four receive antennas, 256 binary control states measured twice, and the same single-path-per-subset model. Each proper complex Gaussian noise variance is the expected squared magnitude. The generator sets measurement noise from mean mixed clean-grid power and total SNR. The receiver only sees the target estimate and independent repeat-difference estimate of coefficient variance.

## Historical target-strength replay

Replay each of the 10,800 previously frozen mean channels and nuisance orders from its recorded seed. For each store the exact per-coefficient variance v=sigma²/512, target energy per entry, target SNR in dB (10 log10 of ||T||²/(128v)), and the weakest visible interaction (minimum pooled clean residual square root divided by sqrt(v) among H). Report medians and first and third quartiles within each of the nine original cells. The minimum ranges over both terminal edges for exact-rank-one channels, and over the entire five-edge path otherwise, so the minimum has a different interpretation at exact degeneracy. The target-strength statistics are evaluation-only.

## Fixed-channel reacquisition

Fix the entire noiseless mixed grid in each of six cases identified by original seed indices: one of the three original regimes, original SNR index 2 (30 dB), class 0 (ABCD), replicate 0 or 1. Selection by identifier precedes measurement and uses no performance scores. For each fixed grid acquire 2,000 independent noisy two-repeat grids. Fixed-case noise seed for replicate j and realization k is SeedSequence([20261119,913802,0,regime,j,k]). Each acquisition is a genuine measurement-space simulation. Gaussian noise on all grid entries is generated explicitly, the full-set projection is applied to the noisy repeat average and vhat is estimated from their differences. Record any true-null rejection before path completion, false positive count for each null pair, family inclusion (all exact orders), exact family selection, conflicts, singleton count and all cardinalities. The nominal per-pair null error limit is 0.05/14, and the simultaneous family exclusion limit is 0.05. Use correct null denominators (9 generic/near, 12 rank one) for descriptive pooled false-positive rates; within-acquisition pair outcomes can be dependent. Counts are conditional on these six fixed channels; no claim of population representativeness.

## Paired perturbation sweep

Draw 25 new channels for each of 24 generating orders. Each of the 600 base draws includes terminal matrices, background, Gaussian intersurface matrices B and rank-one matrices R, independent uniformly drawn orders for shorter subsets, and standard Gaussian pilot noise for both rounds. Base seed is SeedSequence([20261119,913802,1,order_index,replicate]).spawn(3), respectively for factors, shorter-subset orders and noise. Factor and nuisance sampling orders match the previously frozen rank-one population. Hold the complete base draw fixed and use (R+epsilon B)/sqrt(1+epsilon²) on every directed intersurface link at epsilon=0,0.01,0.03,0.10,0.30,0.60,1. The normalization fixes ensemble mean link-entry power; each channel may have its own realized mixed and target powers at each epsilon. Set total mixed-grid SNR to 30 dB throughout by rescaling the same standardized noise. This is a sampled sweep of a continuous parameter with 600 paired bases, not 4,200 independent channels. The near-rank-one condition of the historical data has no power normalization. At zero the noiseless family contains two orders; at positive epsilon there is generically one. Report full-family coverage, exact recovery, any singletons, cardinality, conflicts, null rejection and diagnostics by epsilon. No monotonicity is assumed for sample paths.
