# Noisy reflection-order confidence sets

## Frozen design, 19 November 2026

This project-local plan was fixed before any study trial was run. The target is the set of all compatible Tx-to-Rx orders for the isolated four-surface tensor, permitting each candidate to refit its link factors. Clean links have full entry support almost surely. The simulation is an abstract complex finite multilinear channel with no repeated visits and one order per subset. It is independent of historical confirmation trials.

### Acquisition and populations

Four labeled boards have two independently controlled elements each, with two transmit and four receive ports. All 256 binary element-control states are measured twice on a static channel, with two orthogonal pilot symbols per state. The simulation implements the equivalent post-despreading complex Gaussian observations in NumPy. It generates both actual noisy grids from the mixed response and uses 1024 training symbols, with no separate validation pilots. The full-set coefficient estimate uses 16 orthogonal Walsh characters; in each spatial entry its variance is the train-observation variance divided by 512. An independent estimate of that coefficient variance is the mean squared first-minus-second observation difference divided by 1024. There are 2048 independent complex contrasts. Receiver observations are limited to the isolated target tensor and this estimated variance. This is an inference about that tensor alone.

The direct-channel matrix has iid proper complex Gaussian entries of standard deviation 0.3. Each board's terminal matrices have iid entries of standard deviation 1/sqrt(2). For each directed board pair in the generic population, the internal link is an iid complex Gaussian matrix with entry standard deviation 0.6/sqrt(2). For the exactly rank-one population it is 0.6/sqrt(2) times the outer product of two independent standard complex Gaussian vectors. For the near-rank-one population add 0.03 times the generic Gaussian matrix to the rank-one draw. The generator draws the Gaussian matrix before the two vectors in both stressed populations. Terminal factors and links are shared across all subset responses in one trial. The four-board order is class-balanced. Each shorter subset independently selects a uniformly random order within that subset. Subsets need not follow one hidden order. The ensemble has no geometric or hardware interpretation.

Three populations (generic, near_rank1, rank1) by three total received SNRs (10, 20, 30 dB) by 24 lexicographically enumerated complete orders by 50 independent trials = 10,800 channels. For each channel, the simulator sets the AWGN variance from the mean squared mixed clean-grid response over all controls and antenna pairs. The receiver does not use this variance or this SNR. Independent seeds use NumPy SeedSequence([20261119,773410,regime_index,snr_index,order_index,replicate],spawn_key=(stream,)) with indices starting at zero and streams 0=channel factors, 1=nuisance orders, 2=measurement noise. Each method receives the same data. No tuning, adaptive stopping, new board counts or new populations.

### Fixed decision rules

For each of the 14 possible adjacencies among the six modes (exclude Tx--Rx), sum squared singular values beyond the first across all disjoint conditional matrix slices. For dimensions m,n and b slices, k=b(m-1)(n-1). The pair-specific rule declares an edge if this residual exceeds vhat times k times the 1-0.05/14 quantile of F(2k,4096). The simultaneous global Frobenius ball comparator declares an edge if the same residual exceeds vhat times 128 times the 0.95 quantile of F(256,4096). Both methods return every Tx-to-Rx order containing all declared edges. If none fits, record a conflict and return all 24 permutations. The point comparator maximizes the sum of raw residuals along its candidate path; differing from a normalized sum by a common positive factor, the argmax agrees. It returns the lexicographically first maximizer if a tie occurs. Log near-ties using the original 1e-12 tolerance after normalization. This comparator deliberately forces a single answer.

### Evaluation and reporting

Generic and near-rank-one target tensors have a single compatible order almost surely. Exactly rank-one inter-board links leave the first and last board identified and exactly two possible internal orders. Evaluate the clean compatible set from these structural parameters only after inference. For every cell record simultaneous inclusion of all compatible orders, inclusion of generating order, exact set recovery, mean and median cardinality, cardinality histograms, singletons issued, singleton disagreements with the generating label, structurally false singletons (anything other than the true singleton set) and inconsistent edge graphs. Report point accuracies and their limitation under equivalence. The frequentist coverage target is at least 95% over fresh noise per fixed admissible clean tensor. It is not a conditional-on-release error rate. Overall success rates are empirical balanced-class proportions. Retain per-trial observed tensors, estimated variances, pair scores, candidate masks, ground truth, full trial identifiers, nuisance ordering and summaries for audit. No claim of optimality among all receiver or sensing designs.
